# 사방줄미싱 구현 기준

`Dialog사방줄미싱`은 미싱종류 첫 항목(5mm 로프미싱)과 상·하·좌·우 각각 30mm를 기본값으로 표시한다. 종류와 네 방향 입력 모두 필수이며 간격은 양수다. 8mm 로프미싱도 같은 가이드 규칙을 사용하며 자재 종류를 후가공·PDF 메타데이터에 보관한다.

입력한 방향별 간격은 출력 크기 기준 mm이며 확대 배율을 다시 곱하지 않는다. 그림을 먼저 지정 폭·길이에 배치하고 흰 여백을 추가한다. 원본 영역 경계와 가장 바깥 경계에 K100 검정 사각 가이드를 각각 그린다. 기존 벡터와 종횡비 배치 규칙을 유지하며 여백에 그림을 늘려 채우지 않는다.

참고 PDF는 원본 약 180×120mm에 사방 3mm 간격과 0.17pt 검정선을 적용한 1/10 크기 문서다. 선이 잘리지 않도록 방향별 여유에 선두께의 절반을 포함해 실제 페이지는 약 186.0603×126.0602mm다. 10배 출력의 기본 간격은 각각 30mm이고 선두께는 1.7pt다. 원본 폭·길이를 정수 mm로 반올림한 1800×1200mm로 출력하면 약 1860.5997×1260.5997mm다. 기존 도련이 있으면 바깥에 추가된다.

선두께는 참고의 0.17pt에 현재 배율을 곱한다. 고정 사이즈에서는 입력 폭/원본 폭을 사용한다. 참고 여백의 기존 인쇄작업 식별문구는 새 디자인의 내용이 아니므로 재사용하지 않는다.

방향별 값은 기존 `PostProcessParameters`의 nullable `RopeTopMm`, `RopeBottomMm`, `RopeLeftMm`, `RopeRightMm`에 저장한다. 이전 단일 `DimensionMm` 설정은 네 방향 공통값으로 읽는다. 새 항목은 30mm다. 기존 JSON 저장 테이블을 사용하므로 DB 스키마 변경은 없다.

PDF 생성의 `RopeSewPasses`는 후가공 목록의 순서를 유지한다. 복수 항목은 안쪽부터 순서대로 적용한다. 각목·도련·재단·타공과 함께 적용할 수 있고, 출력 크기와 타공 개수 검증은 미싱 여백을 포함한다. 다른 미싱 종류는 기존 동작을 유지한다.

검증:

- `PdfRopeSewRegression.py`: 참고 PDF 페이지/사각선 비교와 같은 렌더러의 전체 이미지 차이, 10배 출력, 네 방향 독립값, 복수 항목, 각목·도련·재단·타공 병합, 잘못된 입력 거부.
- `RopeSewDialogRegression.cs`: 실제 부모의 추가 버튼 흐름, 기본값, 필수 입력, 반환값, 후가공 요약, JSON 저장·복원, 레거시 값, PDF 설정. 선택 인수로 원본 경로와 출력 경로를 전달하면 실제 .NET 서비스로 PDF도 생성한다.
